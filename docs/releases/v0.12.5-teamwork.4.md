# v0.12.5+teamwork.4

[English backup](v0.12.5-teamwork.4_en.md)

`v0.12.5+teamwork.4` 继续绑定上游 Spec Kit `v0.12.5`，Team 扩展版本升级为
`0.9.0`。

## 主要变化

- 增加项目从 0 到 1 和已有项目新需求的 Requirement → Feature Split 流程；
- 在线 Requirement Issue 和 PR 仍为协作首选，本地记录仅作为具名、可追踪的降级路径；
- Feature Catalog 与 Feature Record 位置可配置，并由首次 Feature Split 询问后锁定；
- `check_plan_and_task.py` 可校验实际 Git diff、Plan 声明范围和 Permission Envelope；
- Team 角色优先使用精简 resolver 输出，减少无关上下文加载；
- Windows 明确使用 UTF-8，并避免 pytest 缓存和字节码污染工作区。

## 发布与安装

在发行 PR 的合并提交创建 `v0.12.5+teamwork.4` tag。tag 存在后使用：

```bash
uv tool install specify-cli --force \
  --from git+https://github.com/EuphoriaYan/spec-kit.git@v0.12.5+teamwork.4
specify init . --integration <codex|claude|cursor-agent|trae>
```

需要回滚时重新安装 `v0.12.5+teamwork.3`，再执行相同的项目刷新命令。
