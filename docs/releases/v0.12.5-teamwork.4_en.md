# v0.12.5+teamwork.4

[中文主文档](v0.12.5-teamwork.4.md)

`v0.12.5+teamwork.4` remains based on upstream Spec Kit `v0.12.5` and updates
the Team extension to `0.9.0`.

## Highlights

- adds Requirement → Feature Split workflows for project bootstrap and new
  requirements in existing projects;
- keeps online Requirement Issues and pull requests preferred while allowing
  attributable, traceable local fallbacks;
- makes Feature Catalog and Feature Record locations configurable and locks
  the first confirmed choice;
- extends `check_plan_and_task.py` to validate the actual Git diff against Plan
  scope and the Permission Envelope;
- uses compact resolver output to reduce irrelevant Team role context;
- defines Windows UTF-8 and cache-safe pytest defaults.

## Release and install

Create `v0.12.5+teamwork.4` on the release PR merge commit. Once the tag
exists, install with:

```bash
uv tool install specify-cli --force \
  --from git+https://github.com/EuphoriaYan/spec-kit.git@v0.12.5+teamwork.4
specify init . --integration <codex|claude|cursor-agent|trae>
```

To roll back, reinstall `v0.12.5+teamwork.3` and run the same project refresh.
